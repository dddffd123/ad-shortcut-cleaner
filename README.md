# 은밀한 청소기

**은밀한 광고를 청소해 주는 은밀한 청소기** (옛 이름: 쇼핑 광고 바로가기 청소기)

재부팅할 때마다 즐겨찾기나 바탕화면에 쿠팡, 지마켓, 마켓컬리, 11번가 같은 쇼핑 링크가 생기고,
지워도 다시 나타나나요? 다른 프로그램이 몰래 넣는 광고 바로가기입니다.
이 프로그램이 찾아서 지우고, 원인 프로그램도 알려 드려요.

## 내려받기

오른쪽 **Releases**에서 최신 zip을 받으세요.

## 사용법

1. 압축을 풉니다. (압축 파일 안에서 바로 실행하지 말고 꼭 풀어서)
2. `run.bat`을 더블클릭합니다.
3. 검사 결과를 보고 지울지 고릅니다.
4. 마지막에 **자동 청소**를 켜면, 광고가 다시 생겨도 알아서 지워 줍니다.

### "Windows의 PC 보호" 창이 떠요

인터넷에서 받은 서명 없는 프로그램이라 Windows가 한 번 확인하는 거예요.
**[추가 정보] → [실행]** 을 누르면 됩니다.
프로그램은 메모장으로 열어 볼 수 있는 PowerShell 스크립트(`cleaner.ps1`)라서, 무엇을 하는지 누구나 확인할 수 있어요.

## 무엇을 하나요

- **알려진 광고**: 광고 목록에 있는 주소. 확실한 광고라서 바로 지웁니다.
- **의심 항목**: 이름은 쇼핑몰인데 주소가 공식 사이트가 아니거나 광고 추적 주소인 것. 보여 드리고 골라서 지웁니다.
- 직접 저장한 공식 사이트 즐겨찾기(예: `https://www.coupang.com`)는 건드리지 않아요.
- 지우기 전에 바탕화면에 백업 폴더를 만들고, 되돌리는 방법을 `정리기록.txt`에 남깁니다.

**검사하는 곳**: 즐겨찾기 폴더, 바탕화면, 시작 메뉴, 작업 표시줄,
Edge / Chrome / 네이버 웨일 / Brave 즐겨찾기 (여러 프로필 포함). Firefox는 아직 지원하지 않아요.

## 자동 청소

로그인 1분 뒤와 1시간마다, 화면에 아무것도 띄우지 않고 검사합니다.

- 알려진 광고만 지웁니다. 의심 항목은 지우지 않고 Windows 알림만 보냅니다.
- 브라우저 창이 열려 있으면 방해하지 않고 다음 차례에 정리합니다.
- 기록: `%LOCALAPPDATA%\AdShortcutCleaner\log.txt`
- 끄려면 다시 실행해서 "자동 청소를 끌까요?"에 Y.

## 광고는 어디서 생기나요

대부분 PC에 깔린 일부 무료 프로그램이 넣어요. 흔한 경우는 두 가지예요.

- 로그인할 때마다 실행되는 **예약 작업**이 쇼핑 즐겨찾기를 다시 만드는 경우
- 다른 프로그램을 설치할 때 **함께 깔리는 관리 프로그램**이 광고 즐겨찾기를 넣는 경우

청소기가 원인으로 보이는 프로그램을 찾으면 알려 드리고, 어떻게 할지 물어봐요.
예약 작업만 지우고 원래 프로그램은 계속 쓰게 할 수도 있어요.

새 광고 주소나 원인 프로그램을 발견하면 **Issues**에 알려 주세요.

## 광고 목록

- **온라인 광고 목록**: 청소기는 실행할 때마다 이 저장소의 [`online-list.txt`](online-list.txt)를 받아 와요.
  새로 발견된 광고 주소가 여기에 추가되면, 프로그램을 다시 받지 않아도 바로 지워져요.
  인터넷이 안 되면 마지막으로 받은 목록을 씁니다.
- **직접 추가하기**: `patterns.txt`를 메모장으로 열어 `[ad]` 아래에 광고 주소를 한 줄 추가하세요.
- 정상 사이트까지 걸리는 너무 넓은 패턴은 자동으로 무시됩니다.

## 동작 환경

Windows 10 / 11, 기본으로 들어 있는 Windows PowerShell 5.1. 따로 설치할 것은 없어요.
