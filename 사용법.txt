은밀한 청소기 v1.5
은밀한 광고를 청소해 주는 은밀한 청소기
(옛 이름: 쇼핑 광고 바로가기 청소기)
================================

[ 이런 분께 ]
재부팅할 때마다 즐겨찾기나 바로가기에 쿠팡, 지마켓, 마켓컬리, 11번가 같은
쇼핑 링크가 생기고, 지워도 다시 나타나는 분.

[ 사용법 ]
1. 압축을 풉니다. (압축 파일 안에서 바로 실행하지 말고 꼭 풀어서)
2. run.bat 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
3. 알려진 광고: Y 를 누르면 지워집니다.
4. 의심 항목: 번호를 골라 지웁니다. (예: 1,3  /  전부: A  /  안 지움: 엔터)
   고르지 않은 항목은 "정상"으로 기억해 다음부터 묻지 않게 할 수 있어요.
5. 광고를 다시 넣는 원인 프로그램이 있으면 어떻게 할지 물어봅니다.
6. 마지막에 자동 청소를 켤지 물어봅니다.

[ 알려진 광고 vs 의심 항목 ]
- 알려진 광고: 광고 목록에 있는 주소. 확실한 광고라 바로 지웁니다.
- 의심 항목: 이름은 쇼핑몰(쿠팡, 지마켓 등)인데 주소가 공식 사이트가 아니거나
  광고 추적 주소인 것. 다른 프로그램이 넣은 광고일 수 있어 보여 드리고 골라서 지웁니다.
- 직접 저장한 공식 사이트 즐겨찾기(예: https://www.coupang.com)는 건드리지 않아요.

[ 자동 청소 ]
로그인 1분 뒤 + 1시간마다 화면에 아무것도 띄우지 않고 검사합니다.
- 알려진 광고만 지웁니다. 의심 항목은 절대 지우지 않고 Windows 알림만 보냅니다.
  알림을 받으면 시작 메뉴의 "은밀한 청소기"를 실행해 확인하세요.
- 브라우저 창이 열려 있으면 방해하지 않고 다음 차례에 정리합니다.
- 기록: %LOCALAPPDATA%\AdShortcutCleaner\log.txt
- 백업: %LOCALAPPDATA%\AdShortcutCleaner\backup (30일 지나면 자동 삭제)
- 끄려면 다시 실행해서 '자동 청소를 끌까요?'에 Y.

[ 광고 목록 추가하기 ]
patterns.txt 를 메모장으로 열어 [ad] 아래에 광고 주소를 한 줄 추가하세요.
정상 사이트까지 걸리는 너무 넓은 패턴은 자동으로 무시됩니다.
새로 발견된 광고 주소는 인터넷으로 자동으로 받아 옵니다(온라인 광고 목록).
인터넷이 안 되면 마지막으로 받은 목록을 씁니다.

[ 검사하는 곳 ]
즐겨찾기 폴더, 바탕화면, 시작 메뉴, 작업 표시줄,
Edge / Chrome / 네이버 웨일 / Brave 즐겨찾기 (여러 프로필 포함)
※ Firefox 는 아직 지원하지 않습니다.

[ 안전장치 ]
- 지우기 전에 바탕화면에 "광고바로가기_백업_날짜" 폴더를 만들어 원본을 보관합니다.
- 되돌리는 방법은 그 폴더의 "정리기록.txt"에 적혀 있습니다.
- 검사만 하려면: 명령 프롬프트에서  run.bat -ScanOnly

[ 광고는 어디서 생기나요 ]
대부분 PC에 깔린 일부 무료 프로그램이 넣습니다. 흔한 경우는 두 가지예요.
- 로그인할 때마다 실행되는 예약 작업이 쇼핑 즐겨찾기를 다시 만드는 경우
- 다른 프로그램을 설치할 때 함께 깔리는 관리 프로그램이 광고 즐겨찾기를 넣는 경우
청소기가 원인으로 보이는 프로그램을 찾으면 알려 드리고, 어떻게 할지 물어봐요.
